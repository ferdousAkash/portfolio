# Md. Ferdous Hasan Zihad Akash — Modern Portfolio

Modern portfolio built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**, combining up-to-date LinkedIn experience & credentials with real project screenshots and repository links.

## Features
- **Dark & Light Theme Toggle** (`Dark` Obsidian Slate default + `Light` Paper theme)
- **Interactive Experience Timeline** filterable by `Leadership & Ops`, `Engineering`, and `Community`
- **Featured Projects Grid & Case Study Modal** with real screenshots and GitHub links
- **Categorized Technical & Operational Stack**
- **Verified Education & Certifications**
- **Print / Save PDF** support via `@media print`

## Quick Start

```bash
npm install
npm run dev
```

## Production Build (Vercel-ready)

```bash
npm run build
```

Output is generated in `dist/`.
